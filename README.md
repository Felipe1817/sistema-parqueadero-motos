# 🅿️ Sistema de Gestión para Parqueadero de Motos

Aplicación de escritorio desarrollada en Python para la gestión y administración de un parqueadero de motocicletas.

## 📋 Descripción

El sistema permite gestionar el registro de vehículos, controlar entradas y salidas, calcular tarifas, generar tickets y consultar información mediante reportes y un dashboard estadístico.

## 🚀 Funcionalidades

- Registro de entrada de vehículos.
- Registro de salida de vehículos.
- Cálculo automático del tiempo de permanencia.
- Cálculo del valor del servicio.
- Dashboard de ingresos.
- Estadísticas y gráficas.
- Generación de tickets.
- Reportes.
- Exportación de información a Excel.
- Configuración de tarifas.
- Persistencia de información mediante SQLite.
- Generación de aplicación ejecutable para Windows.

## 🛠️ Tecnologías

- Python
- PyQt5
- SQLite
- Pandas
- Matplotlib
- ReportLab
- Pillow
- PyWin32
- PyInstaller
